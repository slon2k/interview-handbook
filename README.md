# Interview Handbook

A structured, in-depth interview preparation handbook — organized as a role-specific curriculum rather than a flat list of Q&A.

**Status: work in progress.** Content is being written module by module; see each track's README for what's currently complete.

## Available Tracks

- [.NET — Middle Backend Developer](dotnet/README.md)
- [Frontend — TypeScript and React](frontend/README.md)

## How This Handbook Works

Each track is a roadmap of modules, and each module is a folder of individual topic files. Every topic file follows the same template ([`templates/topic.md`](templates/topic.md)):

`Definition` → `Alternatives & Trade-offs` → `How It Works` → `Application` → `Common Mistakes` → `Common Interview Questions` (basic/intermediate/advanced/follow-up/code-prediction) → `Practical Tasks` → `Readiness Criteria` → `References`.

Modules are prioritized (Critical / High / Medium) so you can triage under time pressure instead of treating every topic as equally important. Each track also has a **Fast Track** page — a short, curated list of the highest-yield topics across the whole track — for when you don't have time to read everything.

## Contributing / Status Tracking

This is a personal, actively-written project. Module READMEs mark their own status (`Complete`, or a topic list still being filled in). There's no separate progress tracker beyond that — check the module you care about.
