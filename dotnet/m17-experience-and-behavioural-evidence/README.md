# Module 17 - Experience and Behavioural Evidence

**Status:** Complete  
**Priority:** High  
**Prerequisites:** All prior modules — this module works best once you have real technical vocabulary and remembered scenarios to draw on.

## Scope

Even though this module isn't purely technical, it should be connected to the technical modules — that's the organizing idea behind everything here. This module doesn't teach a mechanism the way Modules 2-15 do, and it doesn't drill a skill through worked exercises the way Module 16 does. It coaches you through building your *own* answers: a method for structuring them (STAR), specific prompts to help you retrieve a real memory rather than invent one, and a clear sense of what a weak answer looks like for each scenario category — so you can self-assess honestly.

**A deliberate boundary:** nothing in this module writes a story for you or assumes what your career has actually included. The "generic shape" in each file is a labeled template with brackets to fill in, not a finished narrative — filling it in with your own real experience is the whole point.

## Learning Outcomes

By the end of this module, you should be able to:

- Structure any behavioral answer using STAR without rambling, while still sounding natural rather than recited.
- Retrieve real, specific memories for each of the twelve common scenario categories, using the technical modules' vocabulary as a retrieval aid.
- Recognize and avoid the specific weak-answer patterns for each category (vague technical detail, no measurable result, blame, over-rehearsal).
- Anticipate and handle the natural follow-up questions each scenario type invites.

## How This Module Differs From the Rest

Modules 2-15 use a template built for teaching a mechanism (Definition, Alternatives & Trade-offs, How It Works...). Module 16 uses a template built for drilling a skill through worked exercises. This module uses a third template, built for self-coaching: **What Interviewers Are Listening For → Prompts to Find Your Real Story → A Generic Shape (Template Only) → Common Weak Answers → Follow-up Questions to Expect → References**. The References section in each file points to the earlier-module content most likely to supply real technical texture for that scenario — use it as a retrieval aid, not a source of borrowed content.

## Suggested Learning Sequence

1. Read the STAR method file first — everything else assumes it.
2. Work through each scenario category's prompts and actually write down (even just in bullet form) a real memory for each one, before worrying about polish.
3. Practice saying two or three of them out loud, timed to roughly 90 seconds, to calibrate between rambling and over-rehearsing.
4. Revisit any category where you genuinely can't recall a strong example — that's useful information about which parts of your recent experience are thin, not a sign you're doing this module wrong.

## Practical Deliverables

- A real, specific (even if rough) draft answer for each of the twelve scenario categories.
- A timed, spoken run-through of at least three answers, checked against that scenario's "Common Weak Answers" list.
- For at least one answer, a written note of the follow-up questions you'd expect and how you'd actually answer them.

## Interview Coverage

Each scenario file's "Follow-up Questions to Expect" section is the direct interview-coverage equivalent of the other modules' "Common Interview Questions" sections — expect a real interviewer to ask at least one of them after your initial answer.

## References

Every scenario file links to the specific earlier-module content most likely to help you recall and describe a real, technically-grounded story for that category.
